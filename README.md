# 과학 교구 어디 있지?

과학실 교구가 **어느 수납함, 몇 번째 칸**에 있는지 찾아 주는 웹 페이지입니다.

- 화면: `index.html` (깃허브 페이지에 올림)
- 데이터: 구글 시트 (`Code.gs` = 구글 Apps Script)

학생은 검색만 할 수 있습니다. 선생님은 **수정 비밀번호**를 넣고 앱에서 고치거나, 구글 시트에서 바로 고치면 됩니다.

```
학생·교사 브라우저 ──읽기──▶ Apps Script 웹 앱 ──▶ 구글 시트(교구 / 수납함)
        (깃허브 페이지)  ──저장(비밀번호)──▶
```

---

## 1. 구글 시트 준비 (10분)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름은 예를 들어 `과학실 교구 목록`으로 합니다.
2. 메뉴 **확장 프로그램 › Apps Script**를 엽니다.
3. 처음 보이는 `Code.gs`의 내용을 모두 지웁니다. 이 저장소의 `Code.gs` 내용을 **통째로** 붙여 넣고 저장(💾)합니다.
4. 구글 시트 탭으로 돌아가 **새로 고침**합니다. 잠시 뒤 메뉴에 **교구 앱**이 생깁니다.
5. **교구 앱 › 처음 설정하기**를 누릅니다.
   - 처음 한 번은 권한 승인 창이 뜹니다. "확인되지 않은 앱" 경고가 나오면 **고급 › (프로젝트 이름)(으)로 이동**을 눌러 허용합니다. 내가 만든 스크립트라서 나오는 경고입니다.
   - 실행하면 `교구`·`수납함` 시트가 생기고 지금까지 정리한 내용(교구 235종, 수납함 38개)이 채워집니다.
6. **교구 앱 › 수정 비밀번호 정하기**에서 선생님용 비밀번호를 정합니다. 학생에게는 알려 주지 마세요.

> **이미 예전 Code.gs로 시트를 만들어 두었다면**: Apps Script의 코드를 새 `Code.gs`로 통째로 바꾸고 저장합니다. 그다음 **교구 앱 › 처음 설정하기**를 다시 실행하면 새 수납함 구조(기타1~12, 공통8·9, 학용품3, 안전)와 교구 목록으로 덮어씁니다. 이미 배포했다면 **배포 › 배포 관리 › ✏️ › 버전: 새 버전**으로 다시 배포하세요(주소는 그대로입니다). 비밀번호는 지워지지 않습니다.

## 2. 웹 앱으로 배포 (3분)

1. Apps Script 화면 오른쪽 위에서 **배포 › 새 배포**를 누릅니다.
2. 유형 선택(⚙️)에서 **웹 앱**을 고릅니다.
3. 아래처럼 설정합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> "모든 사용자"로 해야 학생들이 로그인하지 않고 볼 수 있습니다. 누구나 교구 목록을 **읽을** 수는 있지만, **저장**하려면 수정 비밀번호가 필요합니다. 구글 시트 파일 자체는 공유하지 않아도 됩니다.

## 3. index.html에 주소 넣기

`index.html`을 메모장이나 VS Code로 열고 아래 줄을 찾습니다(Ctrl+F로 `GAS_URL` 검색).

```js
const GAS_URL = "";
```

따옴표 안에 복사한 웹 앱 주소를 붙여 넣고 저장합니다.

```js
const GAS_URL = "https://script.google.com/macros/s/AKfy…/exec";
```

## 4. 깃허브에 올리기

1. 깃허브에서 **New repository**를 만듭니다. 이름은 예를 들어 `science-equipment`로 하고, Public으로 만듭니다.
2. **Add file › Upload files**로 `index.html`(필요하면 `Code.gs`, `README.md`도)을 올리고 **Commit changes**를 누릅니다.
3. 저장소의 **Settings › Pages**로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
4. 1~2분 뒤 `https://(아이디).github.io/science-equipment/` 주소로 열립니다. 이 주소를 QR코드로 만들어 과학실에 붙여 두면 편합니다.

## 쓰는 방법

| 하고 싶은 일 | 방법 |
|---|---|
| 교구 찾기 | 이름, 다른 이름, 초성(예: `ㅂㅋ`)으로 검색 |
| 폐시약만 보기 | 첫 화면 위쪽 ‘폐시약 처리 예정’ 상자, 또는 `폐시약`·`2027`로 검색 |
| 앱에서 고치기 | **교구 정보 수정** → 비밀번호 → 수납함 누르기 → 교구 이름 눌러 수정 / `+ 교구 추가` → **변경사항 저장** |
| 시트에서 고치기 | 구글 시트 `교구` 시트에서 바로 수정. 저장 버튼 없이 바로 반영됩니다. |
| 엑셀로 받기 | 오른쪽 위 **엑셀로 내려받기**. 시트는 교구 목록, 수납함별 칸, 수납함 요약, 폐시약 목록입니다. |

### 구글 시트에서 직접 고칠 때 규칙

**`교구` 시트** (한 줄 = 교구 하나)

| 열 | 적는 법 |
|---|---|
| 교구명 | 예: `비커` |
| 수량·규격 | 예: `500ml 12개` |
| 수납함 | `수납함` 시트에 있는 이름과 **똑같이** 적습니다(드롭다운). |
| 층 | `위층` / `아래층` (층 구분이 없는 수납함은 `-`) |
| 열 | 칸이 왼쪽·오른쪽 두 줄인 수납함(공통8·9, 기타1·3·5·8·10·12, 안전)만 `왼쪽` / `오른쪽`. 한 줄이면 `-` |
| 칸 | 각 층(두 줄이면 각 줄)의 **위에서부터** 1, 2, 3… |
| 다른 이름 | 학생들이 다르게 부르는 이름. 띄어쓰기로 구분합니다(예: `메스실린더`). |
| 폐시약 처리 연도 | 처리할 연도(예: `2027`). 적으면 앱에 **폐시약**으로 표시되고, 시트에서도 주황색으로 칠해집니다. 처리가 끝나면 그 줄을 지우세요. |
| ID | **비워 두세요.** 앱이 알아서 붙입니다. 이미 있는 값은 바꾸지 마세요. |

**`수납함` 시트**: 칸 수와 배치도의 위치·크기를 정합니다.

| 열 | 적는 법 |
|---|---|
| 위층 칸 수 | 위에서부터 센 칸 수. 한 줄이면 `3`, 왼쪽·오른쪽 두 줄이면 쉼표로 `2,3`(왼쪽 2칸, 오른쪽 3칸) |
| 아래층 칸 수 | 위와 같은 방식. 층 구분이 없는 수납함은 **비워 둡니다**. |
| 분류 | 색을 정합니다: 지구과학(보라)·운동과에너지(파랑)·물질(노랑)·생명과학(초록)·공통(주황)·안전(분홍)·시약/기타(회색) |
| 가로·세로 위치, 너비, 높이 | 배치도에서의 자리. 수납함 한 개가 대략 너비 103, 높이 126입니다. |

수납함 이름을 바꿀 때는 `교구` 시트의 수납함 이름도 함께 바꿔야 합니다. 앱에서 바꾸면 자동으로 같이 바뀝니다.

### 동시에 고칠 때

앱에서 저장하려는 사이에 다른 선생님이 저장했거나 시트가 바뀌었다면, 덮어쓰지 않고 **"그사이 내용이 바뀌었어요"** 안내 후 최신 내용을 다시 불러옵니다. 방금 고친 내용만 다시 입력하면 됩니다.

## 문제 해결

- **"구글 시트에 연결하지 못했어요"**: `GAS_URL`이 `/exec`로 끝나는지, 배포의 액세스 권한이 **모든 사용자**인지 확인하세요.
- **Code.gs를 고친 뒤 반영이 안 됨**: 배포를 새로 만들면 주소가 바뀝니다. 반드시 **배포 › 배포 관리 › ✏️ › 버전: 새 버전 › 배포**로 업데이트하세요. 그래야 주소가 그대로 유지됩니다.
- **비밀번호를 잊음**: 구글 시트 메뉴 **교구 앱 › 수정 비밀번호 정하기**로 새로 정하면 됩니다.
- **GAS_URL을 비워 둔 상태**: 파일 안에 들어 있는 2026-10-01 기준 저장본을 읽기 전용으로 보여 줍니다.
